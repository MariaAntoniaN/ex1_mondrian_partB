# Exercicio 1 - Mondrian - Parte B

Para a proposta b, decidi brincar com o elemento generativo das cores.
Idealizei que, a cada segundo, as cores dos retângulos mudassem para uma cor diferente dentro da paleta de cores primárias do quadro, de forma que o espectador ganhasse uma nova perspectiva da obra e alcançasse o máximo do seu potencial, que não poderia ter sido  alcançado num objeto estático.
Para criar este elemento generativo, usei como base o exemplo dos emojis de animais dados na página do random() no p5.js, que usa o let para criar uma variável, que, dentro daquela paleta de cores, cada quadrado irá escolher aleatoriamente uma dessas cores a cada segundo.
